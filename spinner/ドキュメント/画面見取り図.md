この資料は、画面の配置の図です。作る機能の範囲は「要件定義書」に従います。番号の正は「要件定義書」の「この版で作ること」です。言葉の意味は「要件定義書」の言葉の表に従います。

画面は1枚です。画面IDは SCR-01 です。ファイルは `spinner/index.html` です。別の画面は開きません。

図の寸法は、実物どおりではありません。通常の長さの正は、約4.2cmです。太さの正は、根元と同じ約4.1cmです。

---

## 1. 画面全体（SCR-01）

ハンドスピナーは1個です。画面の中央に置きます。背景は白です。見出し、点数、説明の文字は出しません。倍速ボタンは出します。

```
+------------------+------------------+------------------+
|        上        |        上        |        上        |
|                  |       (丸)       |                  |
| [ 0.5倍 ]------  |        /         |  ------[ 2.5倍 ] |
|                  |    (薄い青)      |                  |
|                  |      /    \      |                  |
|                  |   (丸)    (丸)   |                  |
+------------------+------------------+------------------+
この枠の中全体が、下画面
左の [ 0.5倍 ] は、真ん中から左端までの倍速ボタン
右の [ 2.5倍 ] は、真ん中から右端までの倍速ボタン
```

開いたときは、3本まとめて、真上から左へ15度向けます。図の上の腕は、その左向きです。軸は薄い青、腕は濃い黒、根元は両隣とつながっています。開いたときの先端は丸です。太さは、根元も腕も先端も約4.1cmです。

上画面は、ハンドスピナーの上端より上です。下画面は、画面全体です。倍速ボタンは2つです。1つは真ん中から左端までで 0.5倍 と出します。もう1つは真ん中から右端までで 2.5倍 と出します。

## 2. 図の部品

| 図の印 | 部品 | 内容 | 機能 |
|---|---|---|---|
| 地 | 背景 | 白 | H-1 |
| (薄い青) | 軸 | 画面の真ん中。丸。中心に穴がある。色は薄い青 | H-1 |
| 斜めの線 | 腕 | 軸から3本。太さは根元と同じ約4.1cm。根元は両隣とつながる。色は濃い黒。等しい間隔。通常の長さは約4.2cm。真上から左へ15度 | H-4 |
| (丸) | 先端 | 開いたときは丸。太さは約4.1cm。上画面を押すと四角 | H-4、H-5 |
| 上 | 上画面 | ハンドスピナーの上端より上。押すたびに、先端が丸と四角で替わる | H-5 |
| 下 | 下画面 | 画面全体。押すと、回転が止まる | H-6 |
| [ 0.5倍 ] | 左の倍速ボタン | 真ん中から左端まで。押し続けているあいだ、0.5倍。離すと1.0倍 | H-7 |
| [ 2.5倍 ] | 右の倍速ボタン | 真ん中から右端まで。押し続けているあいだ、2.5倍。腕の長さは約1cmと約8cmのあいだで変わる。離すと1.0倍、長さは約4.2cm | H-8 |

軸、腕、倍速ボタン以外の部品は、この画面に置きません。

ハンドスピナーの上でのクリックとドラッグも、この同じ画面の中で行います。クリックすると、時計回りに回ります。ドラッグしても、何も起きません。ページを開き直すと、回転、四角の先端、腕の長さ、倍率は残らず、開いたときの向きに戻ります。
