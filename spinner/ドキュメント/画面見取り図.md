この資料は、画面の配置の図です。部品の表は「画面設計書」です。作る機能の範囲は「要件定義書」に従います。番号の正は「要件定義書」の「この版で作ること」です。言葉の意味は「用語定義書」に従います。

画面は1枚です。画面IDは SCR-01 です。ファイルは `spinner/frontend/index.html` です。別の画面は開きません。

図の寸法は、実物どおりではありません。通常の長さの正は、約4.2cmです。羽根は薄く、少し曲がっています。

---

## 1. 画面全体（SCR-01）

風車は1個です。画面の中央に置きます。背景は白です。見出し、点数、説明の文字は出しません。倍速ボタンは出しません。

```
+------------------+------------------+------------------+
|        上        |        上        |        上        |
|                  |      赤の羽根     |                  |
|        ↺         |   緑    ピン  青   |        ↻         |
|                  |      黄の羽根     |                  |
|                  |       柄         |                  |
+------------------+------------------+------------------+
この枠の中全体が、下画面
左の ↺ は、風車の左端より左。押すと逆回転
右の ↻ は、風車の右端より右。押すと時計回り
```

開いたときは、4枚まとめて、真上から左へ15度向けます。図の上の羽根は、その左向きです。ピンは濃い黒、羽根は赤、青、黄、緑で、薄く曲がっています。柄はピンの下にあり、木の色で、回りません。

上画面は、風車の上端より上です。下画面は、画面全体です。左画面は、上端より下で、左端より左です。右画面は、上端より下で、右端より右です。上画面を押すと、動きは2.0倍になります。羽根の長さは約4.2cmのままです。柄の長さは変わりません。もう一度押すと、1.0倍に戻ります。左画面を押すと逆回転、右画面を押すと時計回りに回ります。

## 2. 図の部品

| 図の印 | 部品 | 内容 | 機能 |
|---|---|---|---|
| 地 | 背景 | 白 | H-1 |
| ピン | ピン | 画面の真ん中。小さい丸。色は濃い黒 | H-1 |
| 色のついた羽根 | 羽根 | ピンから4枚。薄く、少し曲がる。色は赤、青、黄、緑。等しい間隔。長さは約4.2cmのまま。真上から左へ15度 | H-4、H-5 |
| 柄 | 柄 | ピンの下。木の色。回らない。長さは変わらない | H-1、H-4 |
| 上 | 上画面 | 風車の上端より上。押すと2.0倍。羽根の長さは約4.2cmのまま。もう一度押すと1.0倍。羽根の先は曲がったまま。回転は回り続ける | H-5 |
| 下 | 下画面 | 画面全体。上画面、左画面、右画面、風車以外を押すと、回転が止まる | H-6 |
| ↺ | 左画面 | 上端より下で、左端より左。押すと逆回転。回転は回り続ける | H-7 |
| ↻ | 右画面 | 上端より下で、右端より右。押すと時計回り。回転は回り続ける | H-8 |

ピンと羽根と柄以外の部品は、この画面に置きません。↺と↻は、左右の画面の印です。

風車の上でのクリックとドラッグも、この同じ画面の中で行います。止まっているときにクリックすると、時計回りに回ります。回っているときにクリックすると、その場で止まります。ドラッグしても、何も起きません。ページを開き直すと、Durable Object に残した向き、回転、倍率から続きます。羽根の先は曲がったまま、長さは約4.2cmです。柄は回っていません。

## 3. 重なった場所

下画面は画面全体なので、上画面、左画面、右画面も下画面に含まれます。上画面を押しても、回転は止まりません。変わるのは、倍率だけです。左画面を押すと逆回転、右画面を押すと時計回りで、回り続けます。

いまの `spinner/frontend/index.html` は、この図のとおりです。
