# 機能要件

| 項目 | 内容 |
|---|---|
| 文書名 | 機能要件 |
| 対象システム | ハンドスピナー |
| 版 | 2.2 |
| 作成日 | 2026年10月11日 |
| 作成者 | nsb |
| 関連資料 | 要件定義書、画面見取り図、ER図、ユースケース、データベース設計、技術スタック、`spinner/index.html` |
| 目的 | 利用者ができることを、番号付きで引けるようにする |

この資料は確認用の一覧です。番号の正は「要件定義書」の「この版で作ること」です。  
言葉の意味は「要件定義書」の言葉の表に従います。配置の図は「画面見取り図」、関係の図は「ER図」、利用の流れは「ユースケース」、表の項目は「データベース設計」、採用する技術は「技術スタック」です。機能要件定義書と、部品の表まで書いた画面設計書は、まだ作っていません。

新しい操作は、この資料では足しません。作らないことの正は「要件定義書」の「作らないこと」です。まだ決めていないことは、この一覧でも決めません。

いまの `spinner/index.html` には、H-1 から H-8 がある。軸は薄い青、背景は白、腕は3本で根元がつながっている。

---

## 1. 読み方

| 記号 | 意味 |
|---|---|
| H | ハンドスピナー |

画面は1枚です。ファイルは `spinner/index.html` です。軸の表示も、腕の表示も、回す操作も、この画面の中で行います。

---

## 2. ハンドスピナー

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| H-1 | 軸を表示する | 画面の真ん中に、軸を1つ置く。軸は丸で、中心に穴がある。軸は薄い青。背景は白 | `spinner/index.html` |
| H-2 | クリックで回転する | ハンドスピナーの上で、クリックすると回る。向きは時計回り | `spinner/index.html` |
| H-3 | ドラッグしても反応しない | ドラッグしても何も起きない | `spinner/index.html` |
| H-4 | 腕を3本表示する | 軸から腕を3本出す。3本は、軸の周りに等しい間隔で置く。太さは根元と同じ約4.1cm。根元は両隣の根元とつながる。色は濃い黒。通常の長さは約4.2cm。開いたときの先端は丸で、太さも約4.1cm。開いたときは、真上から左へ15度 | `spinner/index.html` |
| H-5 | 上画面で先端を変える | 上画面を押すと、3本の先端が丸から四角になる。もう一度押すと、丸に戻る | `spinner/index.html` |
| H-6 | 下画面で回転が止まる | 下画面は画面全体。押すと、ハンドスピナーの回転が止まる | `spinner/index.html` |
| H-7 | 左の倍速ボタン | 真ん中から左端までボタンを1つ置く。押し続けているあいだ、動きは0.5倍。離すと1.0倍に戻る | `spinner/index.html` |
| H-8 | 右の倍速ボタン | 真ん中から右端までボタンを1つ置く。押し続けているあいだ、動きは2.5倍。腕の長さは約4.2cmから約1cmまで短くなり、約1秒止まる。そのあと約8cmまで長くなり、約1秒止まる。それからまた短くなる。離すと、速さは1.0倍、長さは約4.2cmに戻る | `spinner/index.html` |

## 3. ハンドスピナーの形

| 項目 | 内容 | 対応する機能 |
|---|---|---|
| 背景 | 白 | H-1 |
| 軸 | 画面の真ん中にある丸。中心に穴がある。色は薄い青 | H-1 |
| 腕の本数 | 3本。軸の周りに、等しい間隔で置く | H-4 |
| 腕の形 | 太さは根元と同じ約4.1cm。根元は両隣の根元とつながる。開いたときの先端は丸で、太さも約4.1cm。色は濃い黒 | H-4、H-5 |
| 腕の長さ | 通常は約4.2cm。2.5倍のあいだ、約1cmと約8cmのあいだで変わる | H-4、H-8 |
| 開いたときの角度 | 真上から左へ15度 | H-4 |

軸、腕、倍速ボタン以外の部品はありません。根元のつながりは、腕の一部です。

## 4. 例外

| 状況 | 扱い | 関係する機能 |
|---|---|---|
| ページを開き直す | 回転、先端の四角、腕の長さ、倍率は残らない。開いたときは中央で止まり、先端は丸、長さは約4.2cm、真上から左へ15度、倍率は1.0倍 | H-1、H-4、H-5、H-6、H-7、H-8 |
| ハンドスピナーの上でクリックする | 時計回りに回る | H-2 |
| ドラッグする | 何も起きない | H-3 |
| 上画面をもう一度押す | 四角の先端が、丸に戻る | H-5 |
| 下画面を押す | 回転が、その場で止まる | H-6 |
| 左の倍速ボタンを押しているあいだ | 倍率は0.5倍。離すと1.0倍に戻る | H-7 |
| 右の倍速ボタンを押しているあいだ | 倍率は2.5倍。腕の長さが約1cmと約8cmのあいだで変わる。離すと1.0倍、長さは約4.2cmに戻る | H-8 |
