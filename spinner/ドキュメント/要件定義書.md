# 要件定義書


| 項目     | 内容                                                          |
| ------ | ----------------------------------------------------------- |
| 文書名    | 要件定義書                                                       |
| 対象システム | ハンドスピナー                                                     |
| 版      | 3.5                                                         |
| 作成日    | 2026年10月11日                                                 |
| 作成者    | nsb                                                         |
| 関連資料   | 用語定義書、機能要件、機能要件定義書、画面見取り図、画面設計書、ER図、ユースケース、データベース設計、技術スタック、`spinner/index.html` |
| 目的     | 本システムで「何を作るか」「何を作らないか」を決める                                  |


この資料は、プログラムを書く前に決める約束です。  
学校の学習課題として、要件を決めてから画面を整え、そのあと実装する流れで作る。言葉の意味の正は「用語定義書」です。


`spinner/index.html` は、ハンドスピナーの画面です。軸、つながった腕3本、先端、左の↺、右の↻がある。止まっているときにクリックすると時計回りに回る。回っているときにクリックすると止まる。左画面を押すと逆回転で回る。右画面を押すと時計回りに回る。ドラッグしても反応しない。上画面を押すと、2.0倍になり、腕の長さが変わる。

費用は 0 円とする。有料のサービスが必要になったときは、実装の前に知らせる。

## 2. この版で作ること


| No. | できること        | 詳細                                                                                 |
| --- | ------------ | ---------------------------------------------------------------------------------- |
| H-1 | 軸を表示する       | 画面の真ん中に、軸を1つ置く。軸は丸で、中心に穴がある。軸は薄い青。背景は白                                             |
| H-2 | クリックで回転し、止まる | ハンドスピナーの上で、止まっているときにクリックすると時計回りに回る。回っているときにクリックすると、その場で止まる。                    |
| H-3 | ドラッグしても反応しない | ドラッグしても何も起きない                                                                      |
| H-4 | 腕を3本表示する     | 軸から腕を3本出す。3本は、軸の周りに等しい間隔で置く。太さは根元と同じ約4.1cm。根元は両隣の根元とつながる。色は濃い黒。通常の長さは約4.2cm。開いたときの先端は丸で、太さも約4.1cm。開いたときは、真上から左へ15度 |
| H-5 | 上画面で2.0倍にする | 上画面を押すと、動きは2.0倍になる。腕の長さは約4.2cmから約1cmまで短くなり、約1秒止まる。そのあと約8cmまで長くなり、約1秒止まる。それからまた短くなる。もう一度押すと、1.0倍に戻り、長さは約4.2cmに戻る。先端は丸のまま。回転は止まらず、回り続ける |
| H-6 | 下画面で回転が止まる   | 下画面は画面全体。上画面、左画面、右画面、ハンドスピナー以外を押すと、回転が止まる                                |
| H-7 | 左画面で逆回転する   | 左画面に↺を置く。押すと、逆回転で回る。回転は止まらず、回り続ける                                            |
| H-8 | 右画面で時計回りに回る | 右画面に↻を置く。押すと、時計回りに回る。回転は止まらず、回り続ける                                          |

## 3. 作らないこと


| 項目              | 理由                       |
| --------------- | ------------------------ |
| 風車や、ハンドスピナー以外の物 | この版で回す物は、ハンドスピナー1つである    |
| 点数やゲーム          | ただ回すだけである                |
| ログイン            | 利用者は nsb 一人であり、本人確認をしない  |
| 他の人との共有         | 一人用であり、同時に他の人と使わない       |
| インターネットへの公開     | 手元のパソコンで開く               |
| サーバとデータベース      | 画面のファイルだけで足りる。回した状態は残さない |
| 有料のサービス         | 課題提出用であり、費用をかけない         |
| 左右の倍速ボタン        | この版では置かない                |
| 0.5倍速           | この版では使わない                |
| 先端を四角にすること      | 上画面は、2.0倍にするために使う        |
| 2.5倍             | この版の倍速は2.0倍である          |


---



## 4. まだ決めないこと

残っているものはありません。

重なった場所は、次のとおりです。下画面は画面全体なので、上画面、左画面、右画面も下画面に含まれます。上画面を押しても、回転は止まりません。変わるのは、倍率だけです。左画面を押すと逆回転、右画面を押すと時計回りで、回り続けます。
