| 目的     | 本システムで「何を作るか」「何を作らないか」を決める                                  |


この資料は、プログラムを書く前に決める約束です。  
学校の学習課題として、要件を決めてから画面を整え、そのあと実装する流れで作る。言葉の意味の正は「用語定義書」です。


`spinner/frontend/index.html` は、風車の画面です。ピン、曲がった羽根4枚、柄、左の↺、右の↻がある。止まっているときにクリックすると時計回りに回る。回っているときにクリックすると止まる。左画面を押すと逆回転で回る。右画面を押すと時計回りに回る。ドラッグしても反応しない。上画面を押すと、2.0倍になる。羽根の長さは変わらない。柄は回らない。

請求は 0 円とする。動かす場所は、手元のパソコンである。向き、回転、倍率は Durable Object に残す。確認用の東京の EC2 は、2026年10月20日に消した。あの EC2 は以前の Node.js の静的配信であり、この版の Durable Object はそこでは動かない。作り直す手順は「AWSデプロイガイド」にある。EC2 を起動するときは、AWS の無料プランの範囲で使う。無料プランを超える構成は作らない。動かす場所、保存、費用、速さは「非機能要件」にまとめる。

| H-8 | 右画面で時計回りに回る | 右画面に↻を置く。押すと、時計回りに回る。回転は止まらず、回り続ける                                          |

## 3. 作らないこと


| 項目              | 理由                       |
| --------------- | ------------------------ |
| 風車以外の物 | この版で回す物は、風車1つである    |
| 点数やゲーム          | ただ回すだけである                |
| ログイン            | 利用者は nsb 一人であり、本人確認をしない  |
| 他の人との共有         | 一人用であり、同時に他の人と使わない       |
| インターネットへの公開     | 不特定の相手には開かない。入れるのは、この PC のアドレスだけである |
| 別のデータベース製品       | PostgreSQL も、RDS も、ファイルの SQLite も置かない。状態は Durable Object に残す |
| 有料のサービス         | 手元の Wrangler は 0 円。EC2 を起動するときは AWS の無料プランだけ使う。無料プランを超えるものは作らない |
| アプリケーションの技術一式   | React、TypeScript、Vite、Tailwind、Java、Spring Boot、Gradle、PostgreSQL は使わない。フロントエンドは HTML、CSS、JavaScript。バックエンドは Cloudflare Workers。状態は Durable Object |
| 左右の倍速ボタン        | この版では置かない                |
| 0.5倍速           | この版では使わない                |
| 先端を四角にすること      | 羽根の先は、曲がった羽根の端のままである       |
| 太い腕と丸い先端        | この版の形は、薄い羽根4枚と柄である       |
| 2.5倍             | この版の倍速は2.0倍である          |
| 2.0倍のあいだの伸び縮み | 羽根の長さは約4.2cmのままである      |

## 4. まだ決めないこと

残っているものはありません。

重なった場所は、次のとおりです。下画面は画面全体なので、上画面、左画面、右画面も下画面に含まれます。上画面を押しても、回転は止まりません。変わるのは、倍率だけです。左画面を押すと逆回転、右画面を押すと時計回りで、回り続けます。

## 5. 完成の定義

確認する人は、利用者の nsb です。自分のパソコンでバックエンドを起動し、ブラウザで `http://127.0.0.1:8787` を開きます。EC2 は 2026年10月20日に消した。あの EC2 は以前の Node.js の静的配信であり、Durable Object は動かない。開き方の正は「操作手順書」と「技術スタック」です。ファイルのダブルクリックは、この版の開き方にしません。

次をすべて満たせば、この版の完成とします。

1. 画面の真ん中に、ピンが1つある。ピンは小さい丸。色は濃い黒。背景は白。柄はピンの下にあり、回らない
2. 羽根が4枚ある。ピンの周りに等しい間隔で、薄く、少し曲がっている。色は赤、青、黄、緑。長さは約4.2cm。向きは、真上から左へ15度。柄は木の色
3. 止まっているときに風車をクリックすると、時計回りに回る。回っているときにクリックすると、その場で止まる
4. ドラッグしても、何も起きない
5. 上画面を押すと、2.0倍になる。羽根の長さは約4.2cmのまま。もう一度押すと、1.0倍に戻る。羽根の先は曲がったまま。柄の長さは変わらない。回転は止まらず、回り続ける
6. 上画面、左画面、右画面、風車以外を押すと、回転が止まる
7. 左画面を押すと、逆回転になる。印は↺。回転は止まらず、回り続ける
8. 右画面を押すと、時計回りになる。印は↻。回転は止まらず、回り続ける
9. ページを開き直すと、Durable Object に残した向き、回転、倍率から続く。初めて開いたときは、中央で止まっている。長さは約4.2cm、向きは真上から左へ15度、倍率は1.0倍、羽根の先は曲がったまま。柄は回っていない

「作らないこと」に書いたものが画面に無いことは、不合格にしません。
