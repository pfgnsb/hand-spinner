# 要件定義書


| 項目     | 内容                                                          |
| ------ | ----------------------------------------------------------- |
| 文書名    | 要件定義書                                                       |
| 対象システム | ハンドスピナー                                                     |
| 版      | 2.6                                                         |
| 作成日    | 2026年10月11日                                                 |
| 作成者    | nsb                                                         |
| 関連資料   | 機能要件、画面見取り図、ER図、ユースケース、データベース設計、技術スタック、`spinner/index.html` |
| 目的     | 本システムで「何を作るか」「何を作らないか」を決める                                  |


この資料は、プログラムを書く前に決める約束です。  
学校の学習課題として、要件を決めてから画面を整え、そのあと実装する流れで作る。用語定義書は、まだ作っていない。この文書で使う言葉は、次のとおりとする。


| 言葉       | 意味                                                                      |
| -------- | ----------------------------------------------------------------------- |
| ハンドスピナー  | この版で回す物。画面に1個だけ置く                                                       |
| 軸        | ハンドスピナーの真ん中にある丸。中心の穴が、回る中心である。色は薄い青                                     |
| 腕        | 軸から外へ伸びる部分。この版では3本。太さは根元と同じ約4.1cm。根元は両隣の根元とつながる。色は濃い黒。通常の長さは約4.2cm。軸の周りに、等しい間隔で出す。開いたときの先端は丸で、太さも約4.1cm |
| 開いたときの角度 | ページを開いた直後、止まっているときの腕の向き。真上から左へ15度                                       |
| 背景       | 画面の地の色。白                                                                |
| 上画面      | ハンドスピナーより上。境目は、ハンドスピナーの上端。押すと、3本の先端が丸と四角で入れ替わる                          |
| 下画面      | 画面全体。押すと、ハンドスピナーの回転が止まる。                                                |
| 左の倍速ボタン  | 画面の真ん中から左端まで置くボタン。押し続けているあいだ、動きは0.5倍。離すと1.0倍に戻る                            |
| 右の倍速ボタン  | 画面の真ん中から右端まで置くボタン。押し続けているあいだ、動きは2.5倍。このあいだ腕の長さが変わる。離すと1.0倍に戻り、長さも通常に戻る |
| 1.0倍速    | クリックで回り始めた、そのままの速さ。倍速ボタンを離すと、この速さに戻る                                       |
| クリック     | ハンドスピナーの上で、クリックすると回る。                                                   |
| ドラッグ     | ドラッグしても反応しない                                                            |
| 回した方向    | クリックしたら、時計回りに回る。                                                        |
| マウスの動かし方 | 関係なし                                                                    |


`spinner/index.html` は、ハンドスピナーの画面です。軸、つながった腕3本、先端、左右の倍速ボタンがある。クリックすると時計回りに回る。ドラッグしても反応しない。

費用は 0 円とする。有料のサービスが必要になったときは、実装の前に知らせる。

## 1. 利用者と利用の前提


| 項目        | 内容                                    |
| --------- | ------------------------------------- |
| 利用者       | nsb 一人                                |
| 説明先       | 提出先。資料の読み手であり、アプリの利用者ではない             |
| ログイン      | なし                                    |
| 他の人との共有   | なし                                    |
| ハンドスピナーの数 | 1個                                    |
| 動かす場所     | 自分のパソコンのブラウザ。`spinner/index.html` を開く |
| 保存        | しない。ページを閉じると、回っていた状態は残らない             |

## 2. この版で作ること


| No. | できること        | 詳細                                                                                 |
| --- | ------------ | ---------------------------------------------------------------------------------- |
| H-1 | 軸を表示する       | 画面の真ん中に、軸を1つ置く。軸は丸で、中心に穴がある。軸は薄い青。背景は白                                             |
| H-2 | クリックで回転する    | ハンドスピナーの上で、クリックすると回る。                                                              |
| H-3 | ドラッグしても反応しない | ドラッグしても何も起きない                                                                      |
| H-4 | 腕を3本表示する     | 軸から腕を3本出す。3本は、軸の周りに等しい間隔で置く。太さは根元と同じ約4.1cm。根元は両隣の根元とつながる。色は濃い黒。通常の長さは約4.2cm。開いたときの先端は丸で、太さも約4.1cm。開いたときは、真上から左へ15度 |
| H-5 | 上画面で先端を変える   | 上画面を押すと、3本の先端が丸から四角になる。もう一度押すと、丸に戻る                                                |
| H-6 | 下画面で回転が止まる   | 下画面は画面全体。押すと、ハンドスピナーの回転が止まる                                                        |
| H-7 | 左の倍速ボタン      | 真ん中から左端までボタンを1つ置く。押し続けているあいだ、動きは0.5倍。離すと1.0倍に戻る                                      |
| H-8 | 右の倍速ボタン      | 真ん中から右端までボタンを1つ置く。押し続けているあいだ、動きは2.5倍。腕の長さは約4.2cmから約1cmまで短くなり、約1秒止まる。そのあと約8cmまで長くなり、約1秒止まる。それからまた短くなる。離すと、速さは1.0倍、長さは約4.2cmに戻る |

## 3. 作らないこと


| 項目              | 理由                       |
| --------------- | ------------------------ |
| 風車や、ハンドスピナー以外の物 | この版で回す物は、ハンドスピナー1つである    |
| 点数やゲーム          | ただ回すだけである                |
| ログイン            | 利用者は nsb 一人であり、本人確認をしない  |
| 他の人との共有         | 一人用であり、同時に他の人と使わない       |
| インターネットへの公開     | 手元のパソコンで開く               |
| サーバとデータベース      | 画面のファイルだけで足りる。回した状態は残さない |
| 有料のサービス         | 課題提出用であり、費用をかけない         |


---



## 4. まだ決めないこと

倍速ボタンは、真ん中から左端までと、真ん中から右端までに1つずつ置くと決めました。残っているのは、次です。


| 項目     | いまの状態                                                   |
| ------ | ------------------------------------------------------- |
| 重なった場所 | 下画面は画面全体なので、上画面や倍速ボタンの場所も下画面に含まれる。同時に変化するか、一方だけかは決めていない |
