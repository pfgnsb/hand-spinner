この資料は、言語、フレームワーク、データベース、実行環境を分けるための選定です。Cloudflare Workers と Durable Objects は実行環境です。言語でも、フレームワークでも、データベース製品でもありません。

費用の請求は 0 円です。無料プランを超えるサービスは入れません。

## 1. 全体の組み合わせ

フロントエンドは `spinner/frontend/index.html` です。バックエンドは `spinner/backend/worker.js` の Hono です。`http://127.0.0.1:8787` の `/api/` を、`spinner/durable-object/pinwheel.js` の SQLite へ渡します。画面の HTML は、Workers の静的配信が渡します。確認用の EC2 は、2026年10月20日に消しました。不特定の相手には開きません。パスの正は「API仕様書」です。

```mermaid
flowchart LR
  browser["ブラウザ"] --> worker["spinner/backend/worker.js"]
  worker --> file["spinner/frontend/index.html"]
  worker --> dob["spinner/durable-object/pinwheel.js"]
```

| 層 | 言語 | フレームワークまたは製品 | 実行環境 | 役割 |
|---|---|---|---|---|
| フロントエンド | HTML、CSS、JavaScript | なし | ブラウザ | ピンと羽根と柄を置く。ログインしてから回す |
| バックエンド | JavaScript | Hono | Cloudflare Workers | `/api/` を受け、SQLite へ渡す。回転の描画は扱わない |
| データベース | SQL | SQLite | Durable Object のストレージ | アカウント、セッション、その人の向き、回転、倍率を残す |

いまの実装の進みは、次のとおりです。

| 場所 | いまの状態 |
|---|---|
| `spinner/frontend/index.html` | フロントエンド。HTML、CSS、JavaScript がある。ログイン欄、ピン、曲がった羽根4枚、柄、左の↺、右の↻がある |
| JavaScript | 同じ HTML の中にある。登録、ログイン、ログアウト、クリックで回す、クリックで止める、ドラッグは反応しない、上画面で2.0倍にする、左画面で逆回転、右画面で時計回り、回転を止める。API を読む、書く |
| `spinner/backend/worker.js` | Hono。`/api/` を Durable Object へ渡す。実行環境は Workers。`127.0.0.1` の 8787 番 |
| `spinner/durable-object/pinwheel.js` | Hono の経路と、SQLite の `users`、`sessions`、`pinwheel`。角度、角速度、倍率はアカウントごとに1行 |

## 2. 採用した版

| 技術 | 区分 | 版 | 置き場所 |
|---|---|---|---|
| HTML | フロントエンドの言語 | ブラウザが読む、ページの書き方 | `spinner/frontend/index.html` |
| CSS | フロントエンドの言語 | ブラウザが読む、見た目の書き方 | 同上。`<style>` の中 |
| JavaScript | フロントエンドとバックエンドの言語 | ブラウザと、Workers が実行する | 画面は `<script>`。サーバは `spinner/backend/worker.js` と `spinner/durable-object/pinwheel.js` |
| Hono | バックエンドのフレームワーク | 4.13.13。`spinner/package.json` の dependency | 上の2ファイル |
| SQLite | データベース | Durable Object が持つ SQLite | `users`、`sessions`、`pinwheel` |
| Cloudflare Workers | 実行環境 | Wrangler がローカルで動かす | `spinner/backend/worker.js` |
| Durable Objects | 実行環境 | Workers と同じ。SQLite の置き場所 | `spinner/durable-object/pinwheel.js` |
| Wrangler | 手元の起動 | `spinner/package.json` の devDependency | `spinner/wrangler.toml` |

ブラウザは、自分のパソコンに入っているものを使います。新しいブラウザの購入はしません。

## 3. 起動

手元のパソコンで動かします。画面を開いたあと、登録またはログインします。待ち受けるアドレスは `127.0.0.1` だけです。いま EC2 は消してあります。Hono と SQLite は、手元の Wrangler の中で動きます。

1. `spinner` フォルダを開く
2. `npm install` を実行する
3. `npx wrangler dev` を実行する
4. ブラウザで `http://127.0.0.1:8787` を開く

止めるときは、起動した画面で `Ctrl+C` を押し、ブラウザのタブを閉じます。

## 4. 採用するもの

| 採用するもの | 層 | 理由 |
|---|---|---|
| HTML | フロントエンド | ピンと羽根と柄を、ページの部品として置く |
| CSS | フロントエンド | ピンの丸、羽根の色、柄、中央への配置を書く。見た目用の別ライブラリは入れない |
| JavaScript | フロントエンドとバックエンド | 画面の動きと、Hono のサーバを同じ言語で書く |
| Hono | バックエンドのフレームワーク | `/api/register`、`/api/login`、`/api/logout`、`/api/me`、`/api/state` を受ける |
| SQLite | データベース | アカウント、セッション、向き、回転、倍率を SQL で残す。PostgreSQL や RDS は置かない |
| Cloudflare Workers | 実行環境 | Hono を動かす場所。言語でもフレームワークでもない |
| Durable Objects | 実行環境 | SQLite を動かす場所。データベース製品ではない |
| Wrangler | 手元の起動 | `127.0.0.1:8787` で Workers と Durable Object を動かす |
| Terraform | 以前の土台 | 東京の EC2 と、この PC だけを許すセキュリティグループ。定義は `infra/`。2026年10月20日に消した。Durable Object は載せない |

## 5. 採用しないもの

選択ボードで採用したものと、アプリケーションで採用したものは、この版では使いません。

| 採用しないもの | 理由 |
|---|---|
| Python | 選択ボードの言語。今回の言語は JavaScript |
| FastAPI | 選択ボードのフレームワーク。今回のフレームワークは Hono |
| Uvicorn | 選択ボードの起動。今回の起動は `npx wrangler dev` |
| Jinja2 | 選択ボードの HTML の組み立て。今回は HTML ファイルをそのまま渡す |
| ファイルに置いた SQLite | 選択ボードの保存の置き方。今回の SQLite は Durable Object のストレージ |
| sqlite3 | Node.js 用の別パッケージ。今回の SQL は Durable Object の SQLite |
| pip と venv | 選択ボードの Python パッケージ。今回のパッケージは npm の Hono |
| 無料プランを超えるサービス | 課題提出用であり、請求は 0 円に保つ。EC2 は無料プランの範囲 |
| React | 別の画面のフレームワーク。今回の画面にフレームワークはない |
| TypeScript | 今回の言語は JavaScript |
| Vite | 別の開発サーバ。今回の起動は `npx wrangler dev` |
| Tailwind | 別の見た目の仕組み。今回の見た目は CSS |
| Java | 別の API の言語。今回の言語は JavaScript |
| Spring Boot | 別の API のフレームワーク。今回のフレームワークは Hono |
| Gradle | 別のビルド。今回の依存は npm |
| PostgreSQL | 別のデータベース。今回のデータベースは SQLite |
