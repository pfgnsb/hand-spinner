## 3. UC-1 風車を開く

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | H-1、H-4 |
| 事前条件 | 自分のパソコンに、`spinner/index.html` がある |
| 事後条件 | 風車が1個、画面の中央に止まって見える |

```mermaid
flowchart TD
  a["spinner/index.html を開く"] --> b[画面の中央に風車を1個出す]
  b --> c[白い背景に、薄い青の軸を出す]
  c --> d[濃い黒の腕を3本出す]
  d --> e[真上から左へ15度向ける]
  e --> f[先端は丸のまま、止まったままにする]
```

軸は丸で、中心に穴があります。腕は太く、太さは根元と同じ約4.1cmです。根元は両隣の根元とつながります。開いたときの先端は丸で、太さも約4.1cmです。軸の周りに等しい間隔です。通常の長さは約4.2cmです。向きは、真上から左へ15度です。

## 7. UC-5 上画面を押す

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | H-5 |
| 事前条件 | 画面が開いている。開いた直後の先端は丸 |
| 事後条件 | 動きは2.0倍になる。腕の長さは約1cmと約8cmのあいだで変わる。もう一度押すと、1.0倍に戻り、長さは約4.2cmに戻る。先端は丸のまま。回転は止まらず、回り続ける |

```mermaid
flowchart TD
  a[上画面を押す] --> b{いまの倍率}
  b -->|1.0倍| c[2.0倍にする]
  c --> e[腕を約1cmまで短くし、約1秒止める]
  e --> f[約8cmまで長くし、約1秒止める]
  f --> g[また短くし始める]
  b -->|2.0倍| d[1.0倍と、約4.2cmに戻す]
```

## 11. この資料に入れないこと

要件定義書で作らないとしたものです。ユースケースにはしません。

- 風車以外の物を回す
- 点数やゲーム
- ログイン
- 他の人との共有
- インターネットへの公開
- サーバとデータベースへの保存
- 有料のサービスを使う
- 左右の倍速ボタン
- 0.5倍速
- 先端を四角にすること
- 2.5倍

重なった場所は、UC-5、UC-7、UC-8 に入れました。上画面を押しても、回転は止まりません。変わるのは、倍率だけです。左画面を押すと逆回転、右画面を押すと時計回りで、回り続けます。
