| 関連資料 | 要件定義書、機能要件、画面見取り図、ER図、`spinner/index.html` |
| 目的 | 利用者が達成することを、流れで示す |

この資料は、利用の流れです。言葉の意味は「要件定義書」の言葉の表に従います。番号の正は「要件定義書」の「この版で作ること」です。関係の図は「ER図」です。

新しい操作は、この資料では足しません。画面は1枚です。ファイルは `spinner/index.html` です。

```mermaid
flowchart LR
```

## 3. UC-1 ハンドスピナーを開く

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | H-1、H-4 |
| 事前条件 | 自分のパソコンに、`spinner/index.html` がある |
| 事後条件 | ハンドスピナーが1個、画面の中央に止まって見える |

```mermaid
flowchart TD
  a["spinner/index.html を開く"] --> b[画面の中央にハンドスピナーを1個出す]
  b --> c[白い背景に、薄い青の軸を出す]
  c --> d[濃い黒の腕を3本出す]
  d --> e[真上から左へ15度向ける]
  e --> f[先端は丸のまま、止まったままにする]
```

軸は丸で、中心に穴があります。腕は細く、開いたときの先端は丸で、軸の周りに等しい間隔です。軸の中心から先端まで約15cmです。向きは、真上から左へ15度です。

## 4. UC-2 ドラッグして回す

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | H-3 |
| 事前条件 | UC-1 のあと、画面が開いている |
| 事後条件 | 離した方向へ回っている。そのあと、だんだん遅くなる。この状態は保存しない |

```mermaid
flowchart TD
  a[ハンドスピナーの上でボタンを押す] --> b[押したままマウスを動かす]
  b --> c[押している間はマウスの位置へ追いかけない]
  c --> d[ボタンを離す]
  d --> e[回した方向へ回り続ける]
  e --> f[回る量と遅くなる速さはマウスの動かし方で変わる]
  f --> g[だんだん遅くなる]
```

---

## 5. UC-3 クリックする

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | H-2 |
| 事前条件 | 画面が開いている |
| 事後条件 | ハンドスピナーの上でのクリックの前と、回転の向きも速さも同じである |

```mermaid
flowchart TD
  a[ハンドスピナーの上で、動かさずにクリックする] --> b[回転は変わらない]
  b --> c{回っているか}
  c -->|止まっている| d[止まったまま]
  c -->|回っている| e[向きと速さはそのまま]
```

## 7. UC-5 上画面を押す

| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 対応する機能 | H-5 |
| 事前条件 | 画面が開いている。開いた直後の先端は丸 |
| 事後条件 | 3本の先端が、押す前と逆の形になる。丸なら四角、四角なら丸 |

```mermaid

  b -->|丸| c[3本とも四角にする]
  b -->|四角| d[3本とも丸に戻す]
```

| 項目 | 内容 |
|---|---|

## 11. この資料に入れないこと

要件定義書で作らないとしたものです。ユースケースにはしません。

- 風車や、ハンドスピナー以外の物を回す
- 点数やゲーム
- ログイン
- 他の人との共有
- インターネットへの公開
- サーバとデータベースへの保存
- 有料のサービスを使う

次は、まだ決めていないので、流れに入れません。

| 項目 | いまの状態 |
|---|---|
| 重なった場所 | 下画面は画面全体なので、上画面や倍速ボタンの場所も下画面に含まれる。同時に変化するか、一方だけかは決めていない |
