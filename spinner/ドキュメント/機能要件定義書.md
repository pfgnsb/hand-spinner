# 機能要件定義書

| 項目 | 内容 |
|---|---|
| 文書名 | 機能要件定義書 |
| 対象システム | ハンドスピナー |
| 版 | 1.1 |
| 作成日 | 2026年10月16日 |
| 作成者 | nsb |
| 関連資料 | 要件定義書、用語定義書、機能要件、画面見取り図、画面設計書、ER図、ユースケース、データベース設計、技術スタック、`spinner/index.html` |
| 目的 | 利用者ができることを、きっかけ、処理、事後条件まで定義する |

この資料は、機能の定義です。番号の正は「要件定義書」の「この版で作ること」です。確認用の一覧は「機能要件」です。言葉の意味は「用語定義書」に従います。配置の図は「画面見取り図」、部品の表は「画面設計書」です。関係の図は「ER図」、利用の流れは「ユースケース」、表の項目は「データベース設計」、採用する技術は「技術スタック」です。

新しい操作は、この資料では足しません。作らないことの正は「要件定義書」の「作らないこと」です。まだ決めていないことは、この定義でも決めません。

画面は1枚です。ファイルは `spinner/index.html` です。利用者は nsb 一人です。保存はしません。ページを閉じると、回転、倍率、腕の長さの変化は残らず、開いたときの状態に戻ります。

## 1. 読み方

| 項目 | 意味 |
|---|---|
| 番号 | 要件定義書の H-1 から H-8。この資料では振り直さない |
| きっかけ | 利用者が行う操作、またはページを開くこと |
| 事前条件 | 処理の前に成り立っていること |
| 処理 | システムが行うこと |
| 事後条件 | 処理のあとで成り立つこと |
| 例外 | その番号だけでは足りないときの扱い |

## 2. H-1 軸を表示する

| 項目 | 内容 |
|---|---|
| 番号 | H-1 |
| できること | 軸を表示する |
| 対応する流れ | UC-1 |
| きっかけ | ページを開く |
| 事前条件 | `spinner/index.html` を開いている |
| 処理 | 画面の真ん中に、軸を1つ置く |
| 事後条件 | 軸が1つ見える。軸は丸で、中心に穴がある。色は薄い青。背景は白 |
| 例外 | ページを開き直すと、開いたときの状態に戻る。軸の形と色は変わらない |
| 画面 | `spinner/index.html` |

## 3. H-2 クリックで回転し、止まる

| 項目 | 内容 |
|---|---|
| 番号 | H-2 |
| できること | クリックで回転し、止まる |
| 対応する流れ | UC-3 |
| きっかけ | ハンドスピナーの上でクリックする |
| 事前条件 | 画面が開いている |
| 処理 | 止まっているときは、時計回りに回す。回っているときは、その場で止める |
| 事後条件 | 止まっていたときは、時計回りに回っている。回っていたときは、止まっている。この状態は保存しない |
| 例外 | ドラッグは、クリックにしない。ドラッグの扱いは H-3。逆回転中にクリックしたときも、その場で止まる |
| 画面 | `spinner/index.html` |

## 5. H-4 腕を3本表示する

| 項目 | 内容 |
|---|---|
| 番号 | H-4 |
| できること | 腕を3本表示する |
| 対応する流れ | UC-1 |
| きっかけ | ページを開く |
| 事前条件 | `spinner/index.html` を開いている |
| 処理 | 軸から腕を3本出す。3本は、軸の周りに等しい間隔で置く |
| 事後条件 | 腕が3本見える。太さは根元と同じ約4.1cm。根元は両隣の根元とつながる。色は濃い黒。通常の長さは約4.2cm。先端は丸で、太さも約4.1cm。向きは、真上から左へ15度 |
| 例外 | 2.0倍速のあいだの長さの変化は、H-5 である。先端は四角にしない |
| 画面 | `spinner/index.html` |

## 6. H-5 上画面で2.0倍にする

| 項目 | 内容 |
|---|---|
| 番号 | H-5 |
| できること | 上画面で2.0倍にする |
| 対応する流れ | UC-5 |
| きっかけ | 上画面を押す |
| 事前条件 | 画面が開いている。上画面は、ハンドスピナーの上端より上 |
| 処理 | 1.0倍速のときは、2.0倍速にする。腕の長さは約4.2cmから約1cmまで短くなり、約1秒止まる。そのあと約8cmまで長くなり、約1秒止まる。それからまた短くなる。2.0倍速のときは、1.0倍速に戻し、長さを約4.2cmに戻す |
| 事後条件 | 倍率は、押す前と逆になる。1.0倍速なら2.0倍速、2.0倍速なら1.0倍速。先端は丸のまま。回転は止まらず、回り続ける |
| 例外 | 下画面と重なる。押しても、回転は止まらない。止まるのは H-6 |
| 画面 | `spinner/index.html` |

## 10. 重なった場所

下画面は画面全体なので、上画面、左画面、右画面も下画面に含まれます。

| 押した場所 | 行うこと | 回転 |
|---|---|---|
| 上画面 | 1.0倍速と2.0倍速を入れ替える。2.0倍速のあいだ、腕の長さが変わる | 止まらず、回り続ける |
| 左画面 | 逆回転にする | 止まらず、回り続ける |
| 右画面 | 時計回りにする | 止まらず、回り続ける |
| ハンドスピナー | 止まっていれば時計回りに回す。回っていれば止める | H-2 に従う |
| それ以外の下画面 | 回転を止める | その場で止まる |

## 11. 作らないこと

要件定義書で作らないとしたものは、この定義に入れません。

- 風車や、ハンドスピナー以外の物
- 点数やゲーム
- ログイン
- 他の人との共有
- インターネットへの公開
- サーバとデータベースへの保存
- 有料のサービス
- 左右の倍速ボタン
- 0.5倍速
- 先端を四角にすること
- 2.5倍速
