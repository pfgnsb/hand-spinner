## 2. 目的から資料を選ぶ

### 言葉と範囲

呼び方は用語定義書です。何を作るか、何を作らないか、完成とみなす条件は要件定義書です。できることの定義は機能要件定義書、番号で引く一覧は機能要件です。環境、残し方、費用、速さは非機能要件です。

### 利用の流れ

開く、ドラッグ、クリック、上画面、下画面、左画面、右画面、開き直す流れはユースケースです。

### データ

関係の図は ER図です。表の項目はデータベース設計です。角度、角速度、倍率は Durable Object の1行に残します。ページを閉じても、その行は残ります。羽根の長さは約4.2cmのままです。

### 技術

使うものと使わないものは技術スタックです。フロントエンドは HTML、CSS、JavaScript です。バックエンドは Cloudflare Workers です。状態は Durable Object です。`npx wrangler dev` のあと、`http://127.0.0.1:8787` を開きます。EC2 は消してあります。作り直す手順は AWSデプロイガイドです。

### 画面

先に形をつかむときは画面見取り図です。部品の表は画面設計書です。開き方と、押したときの手順は操作手順書です。
