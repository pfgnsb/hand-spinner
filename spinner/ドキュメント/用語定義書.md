# 用語定義書

| 項目 | 内容 |
|---|---|
| 文書名 | 用語定義書 |
| 対象システム | 風車 |
| 版 | 1.4 |
| 作成日 | 2026年10月16日 |
| 作成者 | nsb |
| 関連資料 | ドキュメント一覧、要件定義書、機能要件、非機能要件、画面見取り図、ER図、ユースケース、データベース設計、技術スタック、`spinner/index.html` |
| 目的 | このシステムで使う言葉の意味を、一箇所に定める |

この資料は、言葉の意味の正です。資料の入口は「ドキュメント一覧」です。何を作るか、何を作らないかは「要件定義書」に従います。番号の正は「要件定義書」の「この版で作ること」です。

新しい操作は、この資料では足しません。表にない動きを、言葉の意味から足しません。

## 2. 物

| 番号 | 言葉 | 意味 |
|---|---|---|
| 1 | 風車 | この版で回す物。画面に1個だけ置く |
| 2 | 軸 | 風車の真ん中にある丸。中心の穴が、回る中心である。色は薄い青 |
| 3 | 腕 | 軸から外へ伸びる部分。この版では3本。色は濃い黒。軸の周りに、等しい間隔で出す |
| 4 | 根元 | 腕の、軸に近い側。太さは約4.1cm。両隣の根元とつながる |
| 5 | 先端 | 腕の、軸から遠い側の端。丸で、太さは約4.1cm。上画面を押しても、丸のまま |
| 6 | 通常の長さ | 開いたときの腕の長さ。約4.2cm。1.0倍速のときの長さでもある |
| 7 | 開いたときの角度 | ページを開いた直後、止まっているときの腕の向き。真上から左へ15度 |

---

## 3. 画面

| 番号 | 言葉 | 意味 |
|---|---|---|
| 8 | 背景 | 画面の地の色。白 |
| 9 | 上画面 | 風車より上。境目は、風車の上端。押すと、動きは2.0倍速になる。このあいだ腕の長さが変わる。もう一度押すと、1.0倍速に戻り、長さも通常の長さに戻る。回転は止まらず、回り続ける |
| 10 | 下画面 | 画面全体。上画面、左画面、右画面、風車以外を押すと、回転が止まる |
| 11 | 左画面 | 風車の上端より下で、左端より左。印は↺。押すと、逆回転で回る。回転は止まらず、回り続ける |
| 12 | 右画面 | 風車の上端より下で、右端より右。印は↻。押すと、時計回りに回る。回転は止まらず、回り続ける |
| 13 | 印 | 左画面の↺と、右画面の↻。向きを示す印であり、倍速ボタンではない |

上画面、左画面、右画面は、下画面の中に含まれます。重なった場所では、上画面は倍率だけが変わり、左画面は逆回転、右画面は時計回りです。いずれも、押したことで回転は止まりません。

## 4. 動き

| 番号 | 言葉 | 意味 |
|---|---|---|
| 14 | 回転 | 風車が回っている状態。止まっているときは、回転を持たない。ページを閉じると残らない |
| 15 | 時計回り | 時計の針と同じ向き。止まっているときに風車の上をクリックしたときの向き。右画面を押したときの向きでもある |
| 16 | 逆回転 | 時計回りの反対。左画面を押すと、この向きに回る |
| 17 | 回した方向 | 止まっているときに風車の上をクリックすると時計回り。回っているときにクリックすると止まる。右画面は時計回り。左画面は逆回転 |
| 18 | 1.0倍速 | 開いたときの速さ。クリックで回り始めた、そのままの速さ。上画面をもう一度押すと、この速さに戻る。腕の長さは通常の長さに戻る |
| 19 | 2.0倍速 | 上画面を押したときの速さ。1.0倍速の2倍。このあいだ、腕は約4.2cmから約1cmまで短くなり、約1秒止まる。そのあと約8cmまで長くなり、約1秒止まる。それからまた短くなる |
| 20 | 倍率 | 動きの速さの割合。開いたときは1.0倍速。上画面を押すと2.0倍速。もう一度押すと1.0倍速 |
| 21 | クリック | 風車の上で、止まっているときにクリックすると時計回りに回る。回っているときにクリックすると、その場で止まる |
| 22 | ドラッグ | ドラッグしても反応しない |
| 23 | マウスの動かし方 | 関係なし。回る量も、向きも、これでは変わらない |

## 7. この資料で定義しないこと

要件定義書で作らないとしたものは、用語にしません。

- 風車以外の物
- 点数やゲーム
- ログイン
- 他の人との共有
- インターネットへの公開
- データベースへの保存
- 有料のサービス
- 左右の倍速ボタン
- 0.5倍速
- 先端を四角にすること
- 2.5倍速
