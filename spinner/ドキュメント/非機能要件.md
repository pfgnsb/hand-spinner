| 目的 | 機能以外の約束を、環境、残し方、費用、速さまで1枚にまとめる |

この資料は、機能以外の約束です。資料の入口は「ドキュメント一覧」です。できることの番号の正は「要件定義書」の「この版で作ること」です。確認用の一覧は「機能要件」です。機能の定義は「機能要件定義書」です。言葉の意味は「用語定義書」に従います。配置の図は「画面見取り図」、部品の表は「画面設計書」、操作の手順は「操作手順書」です。関係の図は「ER図」、利用の流れは「ユースケース」、表の項目は「データベース設計」、採用する技術は「技術スタック」です。

新しい操作は、この資料では足しません。新しい数字も足しません。作らないことの正は「要件定義書」の「作らないこと」です。

画面は1枚です。ファイルは `spinner/frontend/index.html` です。データベースは `spinner/durable-object/pinwheel.js` の SQLite です。

## 3. 残し方

向き、回転、倍率は、ログインした人の SQLite の1行に残します。PostgreSQL、RDS、ファイルに置いた SQLite は置きません。

| 閉じる前 | 開き直したあと |
|---|---|
| 回っている | 残した角速度で回り続ける |
| 2.0倍速 | 2.0倍速のまま |
| 1.0倍速 | 1.0倍速のまま |
| 羽根の長さ | 約4.2cmのまま |
| 向きが変わっている | 残した角度から続く |
| 羽根の先は曲がっている | 羽根の先は曲がったまま |
| 柄は回っていない | 柄は回っていない |
| 行がまだ無い | 中央で止まっている。真上から左へ15度。1.0倍 |

ピンは1つ、羽根は4枚のままです。色と枚数は、閉じたことで変わりません。

## 4. 費用

| 項目 | 約束 |
|---|---|
| 費用 | 請求は 0 円。EC2 を起動しているあいだは、AWS の無料プランのクレジットを使う。2026年10月20日に消したので、いまはこの構成のクレジットは減らない |
| 有料のサービス | 無料プランの EC2 だけ使う。無料プランを超える構成は作らない |
| 追加のソフト | Node.js が入っていなければ、無料の Node.js を入れる。手元の起動に Wrangler を入れる。実行時のパッケージは Hono |
| フロントエンド | 言語は HTML、CSS、JavaScript。フレームワークはない |

## 5. 速さ

| 項目 | 約束 |
|---|---|
| 開いたとき | 1.0倍速。止まっている |
| 1.0倍速 | クリックで回り始めた、そのままの速さ |
| 2.0倍速 | 1.0倍速の2倍。上画面を押すと、この速さになる |
| 戻し方 | 2.0倍速のあいだに上画面をもう一度押すと、1.0倍速に戻る。羽根の長さは約4.2cmのまま。柄の長さは変わらない |
| 2.0倍速の羽根 | 長さは約4.2cmのまま。伸び縮みはしない |
| 回転 | 2.0倍速にしても、回転は止まらず、回り続ける |
| 使わない速さ | 0.5倍速と2.5倍速は使わない |
| ドラッグ | 速さは変わらない |

1.0倍速は、クリックで回り始めたときの速さです。2.0倍速は、その2倍です。

## 6. この資料に入れないこと

できることの手順は、機能要件定義書と操作手順書にあります。この資料では、手順を足しません。

要件定義書で作らないとしたものも、ここには入れません。

- 風車以外の物
- 点数やゲーム
- ログインしないまま回すこと
- 他の人との共有
- 不特定の相手への公開
- PostgreSQL や RDS への保存
- 無料プランを超えるサービス
- 左右の倍速ボタン
- 0.5倍速
- 先端を四角にすること
- 2.5倍速
