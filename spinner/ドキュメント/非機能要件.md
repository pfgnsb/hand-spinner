| 目的 | 機能以外の約束を、環境、残し方、費用、速さまで1枚にまとめる |

この資料は、機能以外の約束です。資料の入口は「ドキュメント一覧」です。できることの番号の正は「要件定義書」の「この版で作ること」です。確認用の一覧は「機能要件」です。機能の定義は「機能要件定義書」です。言葉の意味は「用語定義書」に従います。配置の図は「画面見取り図」、部品の表は「画面設計書」、操作の手順は「操作手順書」です。関係の図は「ER図」、利用の流れは「ユースケース」、表の項目は「データベース設計」、採用する技術は「技術スタック」です。

新しい操作は、この資料では足しません。新しい数字も足しません。作らないことの正は「要件定義書」の「作らないこと」です。

画面は1枚です。ファイルは `spinner/index.html` です。

## 3. 残し方

保存はしません。データベースの製品も、保存のファイルも置きません。PostgreSQL も、SQLite も使いません。表は、論理的な項目の約束だけです。

| 閉じる前 | 開き直したあと |
|---|---|
| 回っている | 中央で止まっている |
| 2.0倍速 | 1.0倍速 |
| 羽根の長さが変わっている | 約4.2cm |
| 向きが変わっている | 真上から左へ15度 |
| 羽根の先は曲がっている | 羽根の先は曲がったまま |
| 柄は回っていない | 柄は回っていない |

ピンは1つ、羽根は4枚のままです。色と枚数は、閉じたことで変わりません。

## 5. 速さ

| 項目 | 約束 |
|---|---|
| 開いたとき | 1.0倍速。止まっている |
| 1.0倍速 | クリックで回り始めた、そのままの速さ |
| 2.0倍速 | 1.0倍速の2倍。上画面を押すと、この速さになる |
| 戻し方 | 2.0倍速のあいだに上画面をもう一度押すと、1.0倍速に戻る。羽根の長さは約4.2cmに戻る。柄の長さは変わらない |
| 2.0倍速の羽根 | 約4.2cmから約1cmまで短くなり、約1秒止まる。そのあと約8cmまで長くなり、約1秒止まる。それからまた短くなる |
| 回転 | 2.0倍速にしても、回転は止まらず、回り続ける |
| 使わない速さ | 0.5倍速と2.5倍速は使わない |
| ドラッグ | 速さは変わらない |

1.0倍速は、クリックで回り始めたときの速さです。2.0倍速は、その2倍です。

## 6. この資料に入れないこと

できることの手順は、機能要件定義書と操作手順書にあります。この資料では、手順を足しません。

要件定義書で作らないとしたものも、ここには入れません。

- 風車以外の物
- 点数やゲーム
- ログイン
- 他の人との共有
- インターネットへの公開
- サーバとデータベースへの保存
- 有料のサービス
- 左右の倍速ボタン
- 0.5倍速
- 先端を四角にすること
- 2.5倍速
