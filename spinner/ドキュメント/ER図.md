## 2. 論理 ER 図

ハンドスピナーは1個です。軸は1つ、腕は3本です。回転は、画面を開いているあいだだけ、0または1つです。

```mermaid
erDiagram
  ハンドスピナー ||--|| 軸 : 中心に持つ
  ハンドスピナー ||--|{ 腕 : 出す
  ハンドスピナー ||--o| 回転 : 開いているあいだ
  ハンドスピナー {
    string 開いたときの角度
    string 上下の動き
    string 動きの倍率
  }
  軸 {
    string 色
    string 形
  }
  腕 {
    string 色
    string 形
    string 先端
    string 長さ
  }
  回転 {
    string 向き
    string 量
    string 遅くなる速さ
  }
```

## 3. エンティティ

| エンティティ | 意味 | 画面上の呼び方 |
|---|---|---|
| ハンドスピナー | 回す物。今回は常に1個 | 画面中央の1個 |
| 軸 | ハンドスピナーの真ん中。回る中心 | 薄い青の丸 |
| 腕 | 軸から外へ伸びる部分。今回は3本 | 濃い黒の腕 |
| 回転 | 回っているあいだの向き、量、遅さ。保存しない | 回っている状態 |

---

## 4. リレーション

| 関係 | 多重度 | 説明 |
|---|---|---|
| ハンドスピナーと軸 | 1 対 1 | ハンドスピナー1個に、軸はちょうど1つ。軸は必ずこのハンドスピナーに属する |
| ハンドスピナーと腕 | 1 対 3 | ハンドスピナー1個に、腕はちょうど3本。腕の追加と削除はしない。3本は等しい間隔 |
| ハンドスピナーと回転 | 1 対 0または1 | 止まっているときは、回転を持たない。クリックすると、回転を1つ持つ。ページを閉じると、回転は消える |

## 5. 属性

| 論理項目 | 内容 | 備考 |
|---|---|---|
| ハンドスピナー.開いたときの角度 | 真上から左へ15度 | 機能要件 H-4 |
| ハンドスピナー.上下の動き | 下画面を押すと、回転が止まる | 機能要件 H-6 |
| ハンドスピナー.動きの倍率 | 開いたときは1.0倍。左を押しているあいだは0.5倍、右を押しているあいだは2.5倍。離すと1.0倍 | 機能要件 H-7、H-8 |
| 軸.色 | 薄い青 | 機能要件 H-1 |
| 軸.形 | 丸。中心に穴がある | 機能要件 H-1 |
| 腕.色 | 濃い黒 | 機能要件 H-4 |
| 腕.形 | 太い。太さは根元と同じ約4.1cm。根元は両隣とつながる | 機能要件 H-4 |
| 腕.先端 | 開いたときは丸。太さは約4.1cm。上画面を押すと四角。もう一度で丸 | 機能要件 H-4、H-5 |
| 腕.長さ | 通常は約4.2cm。2.5倍のあいだ、約1cmと約8cmのあいだで変わる | 機能要件 H-4、H-8 |
| 回転.向き | 時計回り | 画面を開いているあいだだけ。保存しない（機能要件 H-2） |
| 回転.量 | クリックすると回り続ける。マウスの動かし方では変わらない | 同上 |
| 回転.遅くなる速さ | 使わない。下画面を押すと、その場で止まる | 機能要件 H-6 |

軸と腕以外のエンティティはありません。背景の白と、倍速ボタンは画面の部品です。この図のエンティティにはしません。

## 6. ページを閉じたときの関係

```mermaid
flowchart TD
  a[ページを閉じる] --> b[回転は消える]
  b --> c[開き直すと止まっている]
  c --> d[軸と腕は残る]
  d --> e[先端は丸で、真上から左へ15度]
```

軸と腕は消しません。回転だけが残らない、という約束です（機能要件 H-1、H-4）。

クリックすると、時計回りに回ります（機能要件 H-2）。  
ドラッグしても、回転は変わりません（機能要件 H-3）。
