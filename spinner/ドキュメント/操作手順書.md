## 1. 準備

ログインは要りません。費用は 0 円です。バックエンドは `127.0.0.1` の 3000 番だけで待ちます。起動したあとは、インターネットに繋がっていなくても開きます。

1. フォルダ `spinner` を開く
2. `node server.js` を実行する
3. 入っているブラウザで `http://127.0.0.1:3000` を開く

風車のページが出ます。止めるときは、起動した画面で `Ctrl+C` を押し、ブラウザのタブを閉じます。`index.html` のダブルクリックは、この版の開き方にしません。

## 2. 開いたとき

ページを開いた直後は、次の状態です。

| 見る場所 | 状態 |
|---|---|
| 背景 | 白。見出し、点数、説明の文字はない |
| 風車 | 画面の中央に1個。止まっている |
| 軸 | 薄い青の丸。中心に穴がある |
| 腕 | 3本。濃い黒。等しい間隔。根元は両隣とつながる |
| 先端 | 丸。太さは約4.1cm |
| 腕の長さ | 約4.2cm |
| 向き | 真上から左へ15度 |
| 倍率 | 1.0倍 |
| 印 | 左に↺。右に↻ |

開き直すと、回転、倍率、腕の長さの変化は残らず、この状態に戻ります。

## 3. 基本の操作

### 3.1 クリックして回す、止める

対応は H-2、UC-3 です。

1. 風車の上で、マウスを動かさずに押して離す
2. 止まっていれば、時計回りに回る
3. 回っているあいだに、もう一度同じように押して離すと、その場で止まる

逆回転のあいだに押して離しても、その場で止まります。この操作では、倍率と先端の形は変わりません。

### 3.2 ドラッグする

対応は H-3、UC-2 です。

1. 風車の上でボタンを押す
2. 押したままマウスを動かす
3. ボタンを離す

回転も、腕の長さも、先端も、倍率も、変わりません。

### 3.3 上画面を押す

対応は H-5、UC-5 です。上画面は、風車の上端より上です。印も文字も出ていません。

1. 風車の上端より上を押す
2. 1.0倍速なら、2.0倍速になる。腕は約4.2cmから約1cmまで短くなり、約1秒止まる。そのあと約8cmまで長くなり、約1秒止まる。それからまた短くなる
3. 2.0倍速のあいだにもう一度押すと、1.0倍速に戻る。長さは約4.2cmに戻る

先端は丸のままです。回転は止まらず、回り続けます。上端より上であれば、左右にはみ出た場所も上画面です。

### 3.4 左画面を押す

対応は H-7、UC-7 です。左画面は、上端より下で、風車の左端より左です。印は↺です。

1. ↺のあたり、左画面を押す
2. 逆回転で回る

回転は止まらず、回り続けます。倍率は変わりません。↺そのものは押す部品ではなく、押す範囲は左画面です。

### 3.5 右画面を押す

対応は H-8、UC-8 です。右画面は、上端より下で、風車の右端より右です。印は↻です。

1. ↻のあたり、右画面を押す
2. 時計回りに回る

回転は止まらず、回り続けます。倍率は変わりません。↻そのものは押す部品ではなく、押す範囲は右画面です。

### 3.6 下画面を押す

対応は H-6、UC-6 です。下画面は画面全体です。ここで止めるのは、上画面、左画面、右画面、風車以外を押したときです。

1. 風車の下の空きなど、上画面、左画面、右画面、風車以外を押す
2. 回転が、その場で止まる

倍率と腕の長さは、この押し方では変えません。2.0倍速のあいだに止めても、腕の伸び縮みは続きます。

### 3.7 ページを開き直す

対応は UC-4 です。

1. ブラウザのタブを閉じる
2. バックエンドが動いたまま、`http://127.0.0.1:3000` をもう一度開く

中央で止まります。長さは約4.2cm、向きは真上から左へ15度、倍率は1.0倍、先端は丸です。

## 4. 重なった場所

下画面は画面全体なので、上画面、左画面、右画面、風車も下画面に含まれます。重なった場所では、次の手順を行い、3.6 の停止は行いません。

| 押した場所 | 手順の結果 | 回転 |
|---|---|---|
| 上画面 | 1.0倍速と2.0倍速が入れ替わる。2.0倍速のあいだ、腕の長さが変わる | 止まらず、回り続ける |
| 左画面 | 逆回転になる | 止まらず、回り続ける |
| 右画面 | 時計回りになる | 止まらず、回り続ける |
| 風車 | 止まっていれば時計回りに回る。回っていれば止まる | 3.1 に従う |
| それ以外の下画面 | 回転が止まる | その場で止まる |

---

## 5. この手順に入れないこと

要件定義書で作らないとしたものは、手順にしません。

- 風車以外の物を回す
- 点数やゲーム
- ログイン
- 他の人との共有
- インターネットへの公開
- サーバとデータベースへの保存
- 有料のサービスを使う
- 左右の倍速ボタンを押す
- 0.5倍速にする
- 先端を四角にする
- 2.5倍速にする
