## 1. 準備

請求は 0 円です。バックエンドは `127.0.0.1` の 8787 番だけで待ちます。言語は JavaScript、フレームワークは Hono、データベースは SQLite です。Wrangler を入れたあと、起動中はインターネットに繋がっていなくても開きます。画面を開いたあと、登録またはログインします。

1. フォルダ `spinner` を開く
2. `npm install` を実行する
3. `npx wrangler dev` を実行する
4. 入っているブラウザで `http://127.0.0.1:8787` を開く

EC2 は 2026年10月20日に消してあります。あの EC2 は以前の Node.js の静的配信です。この版の Durable Object は、そこでは動きません。

風車のページが出ます。止めるときは、起動した画面で `Ctrl+C` を押し、ブラウザのタブを閉じます。`index.html` のダブルクリックは、この版の開き方にしません。

## 2. 開いたとき

ページを開いた直後は、次の状態です。

| 見る場所 | 状態 |
|---|---|
| 背景 | 白。見出しと点数はない |
| 風車 | 画面の中央に1個。止まっている |
| ピン | 濃い黒の小さい丸 |
| 羽根 | 4枚。赤、青、黄、緑。薄く曲がる。等しい間隔 |
| 柄 | ピンの下。木の色。回っていない |
| 羽根の長さ | 約4.2cm |
| 向き | 真上から左へ15度 |
| 倍率 | 1.0倍 |
| 印 | 左に↺。右に↻ |
| ログイン欄 | 画面の上。名前とパスワード、登録、ログイン。ログインするまで風車は回らない |

ログインしていないときは、風車は回りません。登録した直後は、中央で止まり、向きは真上から左へ15度、倍率は1.0倍です。同じアカウントで開き直すと、SQLite に残した向き、回転、倍率から続きます。羽根の長さは約4.2cmのままです。柄は回っていません。

## 3. 基本の操作

回す前に、ログインします。対応は A-1、A-2、A-3 です。

1. 画面の上の名前とパスワードを入れる
2. 初めてなら登録を押す。登録済みならログインを押す
3. 名前が表示されたら、風車を回せる
4. ログアウトを押すと、もう一度ログインするまで回らない

名前は英数字、`_`、`-` の1から32文字です。パスワードは8から64文字です。

### 3.1 クリックして回す、止める

対応は H-2、UC-3 です。

1. 風車の上で、マウスを動かさずに押して離す
2. 止まっていれば、時計回りに回る
3. 回っているあいだに、もう一度同じように押して離すと、その場で止まる

逆回転のあいだに押して離しても、その場で止まります。この操作では、倍率と先端の形は変わりません。

### 3.2 ドラッグする

対応は H-3、UC-2 です。

1. 風車の上でボタンを押す
2. 押したままマウスを動かす
3. ボタンを離す

回転も、羽根の長さも、柄も、倍率も、変わりません。

### 3.3 上画面を押す

対応は H-5、UC-5 です。上画面は、風車の上端より上です。印も文字も出ていません。

1. 風車の上端より上を押す
2. 1.0倍速なら、2.0倍速になる。羽根の長さは約4.2cmのまま
3. 2.0倍速のあいだにもう一度押すと、1.0倍速に戻る。長さは約4.2cmのまま

羽根の先は曲がったままです。柄の長さは変わりません。回転は止まらず、回り続けます。上端より上であれば、左右にはみ出た場所も上画面です。

### 3.4 左画面を押す

対応は H-7、UC-7 です。左画面は、上端より下で、風車の左端より左です。印は↺です。

1. ↺のあたり、左画面を押す
2. 逆回転で回る

回転は止まらず、回り続けます。倍率は変わりません。↺そのものは押す部品ではなく、押す範囲は左画面です。

### 3.5 右画面を押す

対応は H-8、UC-8 です。右画面は、上端より下で、風車の右端より右です。印は↻です。

1. ↻のあたり、右画面を押す
2. 時計回りに回る

回転は止まらず、回り続けます。倍率は変わりません。↻そのものは押す部品ではなく、押す範囲は右画面です。

### 3.6 下画面を押す

対応は H-6、UC-6 です。下画面は画面全体です。ここで止めるのは、上画面、左画面、右画面、風車以外を押したときです。

1. 風車の下の空きなど、上画面、左画面、右画面、風車以外を押す
2. 回転が、その場で止まる

倍率は、この押し方では変えません。羽根の長さも柄の長さも変わりません。

### 3.7 ページを開き直す

対応は UC-4 です。

1. ブラウザのタブを閉じる
2. バックエンドが動いたまま、`http://127.0.0.1:8787` をもう一度開く

Durable Object に残した向き、回転、倍率から続きます。長さは約4.2cm、羽根の先は曲がったままです。柄は回っていません。行がまだ無いときだけ、中央で止まり、向きは真上から左へ15度、倍率は1.0倍です。

## 4. 重なった場所

下画面は画面全体なので、上画面、左画面、右画面、風車も下画面に含まれます。重なった場所では、次の手順を行い、3.6 の停止は行いません。

| 押した場所 | 手順の結果 | 回転 |
|---|---|---|
| 上画面 | 1.0倍速と2.0倍速が入れ替わる。羽根の長さは約4.2cmのまま | 止まらず、回り続ける |
| 左画面 | 逆回転になる | 止まらず、回り続ける |
| 右画面 | 時計回りになる | 止まらず、回り続ける |
| 風車 | 止まっていれば時計回りに回る。回っていれば止まる | 3.1 に従う |
| それ以外の下画面 | 回転が止まる | その場で止まる |

## 5. この手順に入れないこと

要件定義書で作らないとしたものは、手順にしません。

- 風車以外の物を回す
- 点数やゲーム
- ログインしないまま回すこと
- 他の人との共有
- 不特定の相手への公開
- PostgreSQL や RDS への保存
- 無料プランを超えるサービスを使う
- 左右の倍速ボタンを押す
- 0.5倍速にする
- 先端を四角にする
- 2.5倍速にする
