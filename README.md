# 風車

画面の中央で回す風車です。学校の課題として、要件を決めてから画面とサーバを作りました。利用者は nsb 一人です。

羽根は4枚で、色は赤、青、黄、緑です。中心にピンがあり、下に柄があります。柄は回りません。

## 開き方

Node.js を使います。追加のパッケージは入れません。

```powershell
cd spinner
node server.js
```

ブラウザで http://127.0.0.1:3000 を開きます。止めるときは、起動した画面で `Ctrl+C` を押します。`index.html` のダブルクリックは、この版の開き方にしません。

サーバは `127.0.0.1` の 3000 番だけで待ち、`spinner/index.html` を渡します。回転はブラウザの中で行い、保存はしません。ページを開き直すと、止まって、長さは約4.2cm、向きは真上から左へ15度、倍率は1.0倍に戻ります。

## 押したとき

| 操作 | 結果 |
|---|---|
| 風車をクリック | 止まっていれば時計回りに回る。回っていれば止まる |
| ドラッグ | 何も起きない |
| 風車より上 | 1.0倍と2.0倍が入れ替わる。羽根の長さは約4.2cmのまま。回転は止まらない |
| 風車より左 | 逆回転。印は↺。回転は止まらない |
| 風車より右 | 時計回り。印は↻。回転は止まらない |
| それ以外 | 回転が止まる |
