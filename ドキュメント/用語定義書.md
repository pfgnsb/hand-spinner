# 用語定義書

| 項目 | 内容 |
|---|---|
| 文書名 | 用語定義書 |
| 対象システム | 選択ボード |
| 版 | 1.3 |
| 作成日 | 2026年10月9日 |
| 作成者 | nsb |
| 目的 | 映画鑑賞の記録で使う言葉の意味を揃え、以後の資料と画面で同じ呼び方を使うため |

この資料は、アプリを作る前に決めておく言葉の辞書です。同じものを、資料ごとに違う名前で呼ばないようにします。

保存の呼び方は、まだこの版には書きません。残し方を決めてから、この表に足します。

---

## 1. 用語一覧

| No. | 用語 | 意味 | 画面上の呼び方 |
|---|---|---|---|
| 1 | 本システム | nsb 一人が、映画を見たいか、見ている途中か、見終わったかを整理するアプリ | 選択ボード |
| 2 | ユーザー | 本システムを操作する人。今回の利用者は nsb 一人。提出先は説明の相手であり、アプリの利用者ではない | （ログインはない） |
| 3 | 利用者 | アプリを実際に操作する人。今回は nsb 一人 | （ログインはない） |
| 4 | 説明先 | 資料を読んで確認する提出先。アプリの利用者ではない | （画面には出ない） |
| 5 | 選択ボード | 状態と作品をまとめて置く台。今回は常に1件 | 画面全体 |
| 6 | ボード名 | 選択ボードに付ける名前 | 画面左上の名前。初期値は「映画鑑賞」 |
| 7 | 状態 | 作品を入れる縦の列。視聴の進みを表す | 列。初期値は「見たい」「途中」「見た」 |
| 8 | 状態名 | 状態の名前 | 各列の上部 |
| 9 | 作品 | 状態の中に置く、映画1本ぶんの枠 | 作品 |
| 10 | 見たい | まだ見ていない作品を置く状態 | 左の列 |
| 11 | 途中 | 見ている途中の作品を置く状態 | 真ん中の列 |
| 12 | 見た | 見終わった作品を置く状態 | 右の列 |
| 13 | 一人用 | 自分だけが使い、他の人と同時に共有しないこと | 本システムの前提 |
| 14 | 追加 | 状態の中に、新しい作品を作ること | 各状態の下部にある「追加」 |
| 15 | 編集 | すでにある作品の名前を直すこと | 作品の「編集」 |
| 16 | 削除 | 作品を消すこと | 作品の「削除」 |
| 17 | 確認 | 削除の前に、本当に消すか聞くこと | 「（作品の名前）を削除しますか？」 |
| 18 | 移動 | 作品をつまんで、同じ状態の中の位置、または別の状態へ置くこと | （ボタンはない。作品をつかむ） |
| 19 | ユースフロー | やりたいことを達成する道筋 | （画面には出ない） |
| 20 | 操作フロー | 画面上のクリックなど、手を動かす手順 | （画面には出ない） |
| 21 | 非機能要件 | 速さ、残し方、動かす環境など、機能以外の約束 | （画面には出ない） |

---

## 2. 似ている言葉の使い分け

| 呼び方 | 使うとき |
|---|---|
| 選択ボード | 資料の中では、台そのものの正式名称とする |
| 映画鑑賞 | 選択ボードの名前。台そのものの呼び方には使わない |
| 状態 | 資料の中では、縦の列の正式名称とする |
| 列 | 画面の説明で、見た目を伝えるときにも使ってよい。状態と同じものを指す |
| 作品 | 映画1本を表す枠。資料でも画面でもこの呼び方に揃える |
| 1本 | 本数を数えるときの言い方。枠の名前には使わない |
| 利用者 | アプリを操作する人。今回は nsb 一人 |
| 説明先 | 資料を読む提出先。アプリの利用者ではない |
| ユースフロー | やりたいことを達成する道筋 |
| 操作フロー | 画面上のクリックなど、手を動かす手順 |
| 非機能要件 | 機能以外の約束。できることの手順ではない |

---

## 3. この資料の使い方

- 要件定義書、画面の説明、プログラムの説明では、この表の用語を使う
- 新しい言葉が必要になったら、この表に足してから使う
- 同じ意味の言葉を、資料ごとに別の名前で書かない
