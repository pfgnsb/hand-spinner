# 要件定義書

| 項目 | 内容 |
|---|---|
| 文書名 | 要件定義書 |
| 対象システム | 選択ボード |
| 版 | 1.1 |
| 作成日 | 2026年10月9日 |
| 作成者 | nsb |
| 関連資料 | 用語定義書、フォルダ直下の `index.html` |
| 目的 | 本システムで「何を作るか」「何を作らないか」を決める |

この資料は、プログラムを書く前に決める約束です。言葉の意味は「用語定義書」に従います。  
学校の学習課題として、要件を決めてから画面を整え、そのあと実装する流れを体験するために作る。

フォルダ直下の `index.html` は、選択ボードの画面です。作品の追加、編集、削除、移動は、この画面の中だけで行い、ページを閉じると元に戻ります。

---

## 1. 利用者と利用の前提

| 項目 | 内容 |
|---|---|
| 利用者 | nsb 一人 |
| 説明先 | 提出先。資料の読み手であり、アプリの利用者ではない |
| ログイン | なし |
| 他の人との共有 | なし |
| 選択ボードの数 | 1件 |
| ボード名 | 映画鑑賞。画面左上に出す |
| 最初からある状態 | 見たい、途中、見た |
| 動かす場所 | 自分のパソコンのブラウザ。`index.html` を開く |

---

## 2. この版で作ること

| No. | できること | 詳細 |
|---|---|---|
| B-1 | 選択ボードを表示する | 開くと、選択ボードが1件見える |
| B-2 | ボード名を表示する | 左上に「映画鑑賞」と出す。この版では書き換えない |
| S-1 | 状態を表示する | 「見たい」「途中」「見た」の3つを、左から並べる |
| W-1 | 作品を表示する | 各状態の中に、作品の名前を出す。最初に見える見本は、見たいに「君の名は。」と「インターステラー」、途中に「三体」、見たに「ショーシャンクの空に」 |
| W-2 | 作品を追加する | 各状態の「追加」で、名前を入れてその状態の末尾に作る。空の名前では作らない |
| W-3 | 作品を編集する | 作品の「編集」で名前を直す。空の名前では反映しない |
| W-4 | 作品を削除する | 作品の「削除」で消す。消す前に確認する |
| W-5 | 作品を移動する | 作品をつまんで、同じ状態の中の好きな位置、または別の状態へ置く |

---

## 3. 作らないこと

| 項目 | 理由 |
|---|---|
| ログイン | 利用者は nsb 一人であり、本人確認をしない |
| 他の人との共有 | 一人用であり、同時に他の人と使わない |
| AWS | 今回の学習範囲に入れない。手元のパソコンで開く |
| Git | 今回の学習範囲に入れない |

---

## 4. まだ決めないこと

保存は、この版では約束しない。ページを閉じると、追加・編集・削除・移動の結果は残らない。作らないと決めたわけではない。
